# Scientific Computing: Coffee Production Analysis

## Project Overview

This project applies scientific computing and numerical methods to analyze
monthly coffee production data from January 2018 to December 2030.

The analysis focuses on modeling the production growth pattern, validating
the selected model through Taylor Series approximation, determining when
production will reach the warehouse capacity limit using the Newton-Raphson
method, and analyzing production changes and cumulative volume using numerical
differentiation and integration.

The main objectives are to:

- Compare exponential and 3rd-order polynomial regression models.
- Identify the model that best represents the accelerating production trend.
- Validate the selected exponential model using a 20-term Taylor Series.
- Estimate when production will reach the 25,000-unit warehouse capacity.
- Determine the required warehouse construction commencement date based on
  the 13-month construction lead time.
- Analyze monthly production rates using O(h^4) numerical differentiation.
- Estimate cumulative production using the Trapezoidal Rule.

The results provide a numerical basis for production forecasting and proactive
warehouse capacity planning.
